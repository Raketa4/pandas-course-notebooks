# Блокноты курса «Анализ данных на Python: pandas»

Графики к курсу [«Анализ данных на Python: pandas»](https://stepik.org/course/306672/promo) на Stepik.

В задаче на код Stepik показывает только текст, поэтому нарисованный график там виден лишь наброском из символов. Здесь — настоящие картинки. Блокнот сам скачивает данные уроков, запускает примеры с графиками, а в ячейку каждой задачи с графиком можно вставить своё решение со Stepik и увидеть результат.

Блокнот открывается в Google Colab кнопкой «Open in Colab»: нужен только аккаунт Google, устанавливать ничего не нужно. Готовых решений здесь нет — проверка и баллы на Stepik.
